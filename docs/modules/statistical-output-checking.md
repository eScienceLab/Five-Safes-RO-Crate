# Module: Statistical Output Checking

A module of the [Five Safes RO-Crate profile](../index.md). It is declared alongside the core profile in an RO-Crate's `conformsTo`.

## Scope

Checks of statistical outputs, such as tables, figures, and summary statistics, before release from a TRE. Trained models are covered by [Trained Model Output Checking](trained-model-output-checking.md); an RO-Crate recording both kinds of check declares both modules.
